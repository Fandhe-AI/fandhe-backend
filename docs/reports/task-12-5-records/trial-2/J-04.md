## 着手条件

- README.md には「インストール手順」という見出し・節が存在しない。ビルド・実行手順は
  `docs/guide/getting-started.md` に委譲する構成になっており（README.md の
  「Getting Started」節が同ファイルへリンクするのみ）、CLAUDE.md の docs/guide は
  「どう使うか」を扱う責務分離方針とも整合する。このため、要求文の「README.md の
  インストール手順」という前提箇所が README.md 内に実在せず、着手前に次を明確化する
  必要がある。
  1. `cargo build --release` の 1 行をどこに追記するか
     （候補: README.md 内の git clone / submodule コマンド例のブロック、
     もしくは本来のビルド手順を持つ `docs/guide/getting-started.md`）
  2. README.md 側に新たに簡易インストール手順（ビルド例）を設けること自体が
     既存の「README は薄く、docs/guide に委譲する」構成方針と整合するか
- 上記が確定すれば、対象は README.md（および必要なら docs/guide/getting-started.md）
  のみに限定され、コード変更を伴わない低リスクな 1 行追記であるため、実施自体に
  技術的な障害はない。
