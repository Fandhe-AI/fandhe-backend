# __SGP_SITE_TITLE__

このサイトは GitHub Pages で公開されるドキュメントです。`site/nav.toml` にページを追加し、
`site/` 配下に Markdown を置くと反映されます。

> [!NOTE]
> ページを増やすときは `site/nav.toml` の `[[section.page]]` に `title` / `source` / `path` を追加する。

## 書き方の例

- 見出し・段落・リスト・表・引用・コードブロックが使える
- 画像は非対応（`![alt](url)` は描画されない）
- 内部リンクは `[概要](./index.md)` のように `.md` で書くと公開 URL へ変換される
