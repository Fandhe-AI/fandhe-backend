# 日本語出力スタイル

## 基本

- ユーザーとのやりとり・説明・コミットメッセージ本文・PR 本文・Issue・コメントは**日本語**で書く
- 技術用語・コード識別子・crate 名・コマンドは原語のまま（無理に訳さない）
- 正書法を守る。ダイアクリティカルマーク付き文字を ASCII 代替にしない（`für` を `fur` にしない等）

## トーン

- 簡潔・具体的に。冗長な前置きや過剰な謝辞を避ける
- 不確実なことは不確実と明示する。断定と推測を区別する
- 結論を先に述べ、根拠を添える

## コード内

- doc comment・コメントは日本語で役割・契約・文脈を書く（[[code-comment-style]]）
- ログメッセージは運用者が読む前提で簡潔な日本語。機密情報を含めない（[[security]]）

## コミット・PR

- Conventional Commits の type/scope は英語規約、description・本文は日本語でよい（[[conventional-commits]]）
